# Student-Database-Application-
This project is a simple Student Management System developed using MongoDB. It demonstrates basic database operations such as creating a database and collection, inserting student records, retrieving data, updating existing records, and deleting records. The project helps users understand CRUD (Create, Read, Update, Delete) operations in MongoDB.

# Student Management System (MongoDB CRUD Application)

## 📌 Project Overview

Student Management System is a Full Stack Web Application developed using Node.js, Express.js, MongoDB, and EJS. The application allows users to manage student records efficiently by performing CRUD (Create, Read, Update, Delete) operations.

This project demonstrates how a web application communicates with a MongoDB database through a backend server and provides a user-friendly interface for managing student information.

---

## 🚀 Features

- Add new student records
- View all student records
- Update existing student details
- Delete student records
- Responsive and simple user interface
- MongoDB database integration
- RESTful CRUD operations
